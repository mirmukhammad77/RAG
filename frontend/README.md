# RAG frontend

This directory is reserved for the frontend application. Its framework and tooling have not been selected yet.

Keep the frontend's source, `package.json`, lockfile, build configuration, and `.env.example` in this directory. Install frontend dependencies and run frontend commands from here.

The NestJS backend lives in [`../api`](../api/README.md) and uses port 3000 by default. Configure the frontend's API URL or development proxy when the frontend is implemented.
